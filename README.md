🍔 Online Food Ordering System
📌 Project Description

The Online Food Ordering System is a Java-based application designed to simplify the process of browsing food items and placing customer orders. The system allows users to view the available menu, select food items, specify quantities, and calculate the total bill.

The project is developed using Java and Object-Oriented Programming (OOP) concepts, with MySQL used for storing and managing food and order-related data. It provides practical implementation of Java programming, database connectivity, and basic CRUD operations.

✨ Features
View available food items
Search/select food items
Add food items to an order
Specify quantity
Calculate total bill
Store customer order details
Manage food item records
Retrieve order information from the database
🛠️ Technologies Used
Java
Object-Oriented Programming (OOP)
MySQL
JDBC
SQL
